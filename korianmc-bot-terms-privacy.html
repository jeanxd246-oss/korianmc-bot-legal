1. Términos de Servicio

Al invitar, configurar o utilizar KORIANMC BOT (en adelante, «el Bot»), aceptas estos Términos de Servicio. Si no estás de acuerdo, deja de utilizar el Bot y solicita a un administrador que lo retire de tu servidor.

Uso permitido

Debes utilizar el Bot de forma legal, respetuosa y de acuerdo con las reglas de Discord. No puedes utilizarlo para acosar, amenazar, enviar spam, distribuir contenido ilegal, vulnerar la seguridad de cuentas o servidores, ni interferir con el funcionamiento de Discord o del Bot.

Administración del servidor

Quien invite o configure el Bot es responsable de comprobar sus permisos y ajustes. Otorga únicamente los permisos necesarios para las funciones que quieras utilizar. Las acciones de moderación y otras funciones administrativas deben utilizarse de manera responsable y de acuerdo con las reglas de tu comunidad.

Disponibilidad y cambios

El Bot se ofrece «tal cual» y puede modificarse, suspenderse o dejar de estar disponible temporal o permanentemente, por ejemplo, por mantenimiento, fallos técnicos o cambios en Discord. No garantizamos un funcionamiento ininterrumpido ni que todas las funciones permanezcan disponibles.

Limitación de responsabilidad

En la medida permitida por la legislación aplicable, el responsable del Bot no garantiza que el servicio esté libre de errores y no será responsable de pérdidas indirectas causadas por interrupciones, errores de configuración o el uso que terceros hagan del Bot. Esto no excluye responsabilidades que legalmente no puedan excluirse.

Suspensión del acceso

Podemos limitar o retirar el acceso al Bot cuando exista un uso abusivo, ilegal, perjudicial o contrario a estos términos, o cuando sea necesario para proteger el servicio y a sus usuarios.

Relación con Discord

KORIANMC BOT es una aplicación de terceros y no está patrocinada, respaldada ni administrada por Discord Inc. El uso de Discord también está sujeto a los Términos de Servicio de Discord.

Cambios en estos términos

Podemos actualizar este documento cuando cambien las funciones o los requisitos del servicio. La versión vigente se publicará en esta página. Si continúas utilizando el Bot después de una actualización, se entenderá que aceptas los términos revisados, en la medida permitida por la ley.

2. Política de Privacidad

Esta sección explica, de forma general, qué información puede procesar KORIANMC BOT para prestar sus funciones. La información concreta depende de las funciones habilitadas y de la configuración de cada servidor.

Información que puede procesarse

  • Identificadores de Discord de usuarios, servidores, canales y roles necesarios para ejecutar comandos y aplicar configuraciones.
  • Opciones de configuración del servidor, como canales, roles, categorías y preferencias relacionadas con las funciones del Bot.
  • Contenido que un usuario envíe directamente al Bot mediante comandos, formularios o sistemas de soporte, cuando esas funciones estén habilitadas.
  • Registros técnicos o de errores necesarios para mantener y proteger el funcionamiento del servicio.

Importante: antes de publicar esta página, revisa que esta lista coincida con el código real del Bot. Elimina cualquier dato que el Bot no procese y añade cualquier dato que sí almacene.

Cómo se utiliza la información

La información se utiliza únicamente en la medida necesaria para ejecutar comandos, guardar ajustes, prestar las funciones solicitadas, moderar o proteger el servicio, solucionar errores y prevenir abusos.

Almacenamiento y conservación

Los datos pueden conservarse mientras sean necesarios para las funciones del Bot o para fines operativos legítimos. Los periodos de conservación dependen del tipo de dato y de la configuración técnica. No publiques una promesa de eliminación automática si el código no la implementa.

Acceso y divulgación

No vendemos deliberadamente información personal. La información puede ser procesada por proveedores de infraestructura necesarios para alojar el Bot, o divulgada cuando sea exigido por la ley o resulte necesario para responder a abusos, proteger derechos o mantener la seguridad del servicio.

Seguridad

Se aplican medidas razonables para proteger la información procesada, pero ningún sistema puede garantizar seguridad absoluta. Nunca compartas contraseñas, tokens de bot ni códigos de autenticación con el equipo del Bot.

Tus opciones

Puedes dejar de utilizar el Bot y pedir a los administradores de tu servidor que lo retiren. Para consultar, corregir o solicitar la eliminación de información relacionada con el Bot, utiliza el servidor de soporte indicado abajo. Algunas informaciones podrían mantenerse cuando exista una razón técnica, de seguridad o legal válida.

Menores de edad

El Bot está destinado a personas que pueden utilizar Discord de acuerdo con los requisitos de edad aplicables en su región. No solicites ni envíes información personal sensible a través del Bot.

Actualizaciones de privacidad

Esta política puede actualizarse para reflejar cambios en el Bot o en los requisitos aplicables. La fecha de actualización se mostrará al inicio de esta página.
